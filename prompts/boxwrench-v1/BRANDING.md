# Benchmark branding

The benchmark identity is deliberately restrained: dark ink, chrome, brass, and one crimson visor accent. The supplied mark reads `BX-77 // BENCHMARK` and uses the existing Boxwrench wrench-head geometry.

## Rules

- Preserve the unbranded generator output as the canonical benchmark artifact.
- Add branding only to a derived social copy after timing, hashing, and quality review.
- Use `branding/boxwrench-benchmark-bug.svg` as the vector master.
- Place it in the lower-right safe area at 16–20% of frame width.
- Keep at least 2.5% frame-width clearance from the right and bottom edges.
- Never cover a face, the crimson visor, a hand/tool contact point, or benchmark evidence.
- Do not add an intro; an intro changes the delivered duration shown in the headline.
- If an end card is later added, report the generated duration separately from the posted duration.

The brand mark is presentation metadata, not model output. Its use must never change which generation wins a comparison.
