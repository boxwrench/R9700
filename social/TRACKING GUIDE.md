The status is `posted-user-reported` because both posts were reported as published. Paste each public X URL into its folder's `POST RECORD.md` and the matching row of `POST TRACKER.tsv` when available.

For simple performance tracking, record these at roughly 24 hours and 7 days:

- views;
- likes;
- reposts;
- replies;
- bookmarks, if visible;
- profile visits or follows attributable to the post, if visible.

Do not rewrite the saved post text after publishing. If a correction is needed, save it as a new reply file so the local record continues to match what was posted.
