# Licensing boundary

No license file has been selected for this repository yet. Until one is added,
the repository contents should not be assumed to be freely reusable.

Model weights are not included. Check each upstream model repository and its
current terms before downloading or redistributing weights. Private access or
authorization correspondence is intentionally outside this repository.

The five Boxwrench reference frames and branding files are copied from the
local benchmark source with their integrity manifest; their upstream ownership
and reuse terms still need to be documented before broad redistribution.
