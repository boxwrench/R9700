If you see this, check this

SymptomFirst check
Model loading takes minutes; one CPU core busy; GPU mostly idleCheck --disable-mmap
H3 changed-prompt sampler runs ~25–30s instead of ~22sCheck Qwen3-VL residency before the sampler
LTX short prompt spends ~22s in conditioningCheck the Gemma minimum sequence floor (LTX_GEMMA_MIN_LENGTH=256)
Music spends ~20s in conditioning before a ~3.6s DiT stepInspect the AR conditioner, not the DiT
